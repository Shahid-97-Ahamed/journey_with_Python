1input() — ব্যবহারকারীর কাছ থেকে তথ্য নেওয়া

2if / elif / else — শর্ত
Structure
গঠন
if শর্ত১: # শর্ত১ True হলে elif শর্ত২: # শর্ত২ True হলে else: # কোনোটাই না হলে
⚠️ মনে রাখো
শর্তের পরে : দিতে হবে। ভেতরে 4 space দিতে হবে। else-এ কোনো condition লেখা যায় না!
Grade Example
উদাহরণ
marks = float(input("Marks: ")) if marks >= 90: print("A+") elif marks >= 80: print("A") elif marks >= 70: print("B") elif marks >= 60: print("C") else: print("F")
3Ternary Operator — এক লাইনে if/else
Structure
গঠন
value = "A" if শর্ত else "B"

শুধু ২টি option → Ternary ✅
৩+ option → if/elif/else ✅

Example
উদাহরণ
age = int(input("Age: ")) status = "Eligible" if age >= 18 else "Not Eligible" print(status)
4Logical Operators — and / or / not
and — এবং
দুটোই True হলে
if age >= 18 and has_id: print("Entry ✅")

True AND True = True
True AND False = False

or — অথবা
যেকোনো একটি True
if is_student or is_senior: print("Discount ✅")

True OR False = True
False OR False = False

not — না / উল্টো
True→False, False→True
if not is_raining: print("Go outside ☀️")

not True = False
not False = True

7File System — ফাইল সিস্টেম
Concept 01
File System কী?

OS যেভাবে disk-এ file store, organize, retrieve করে। Library catalog-এর মতো।

Concept 02
Tree Structure

উল্টো গাছের মতো। সবার উপরে Root। নিচে folder → subfolder → file।

Concept 03
Paths

প্রতিটি file-এর "ঠিকানা"। Root থেকে destination পর্যন্ত।

Absolute Path
Root থেকে পুরো ঠিকানা
Windows: C:\Users\YourName\Projects\main.py Mac/Linux: /home/yourname/projects/main.py
Relative Path
এখান থেকে ঠিকানা
main.py ← same folder ./main.py ← explicitly here ../other/f.py ← go up, then in
⚠️ Key Insight
Python বলে FileNotFoundError → প্রায় সবসময় ভুল path! Absolute vs Relative double-check করো।

10Algorithms — অ্যালগরিদম
Definition
Algorithm কী?

Ordered, finite instructions যা একটি নির্দিষ্ট সমস্যা solve করে। শুরু, স্পষ্ট ধাপ ও শেষ থাকতে হবে।

Properties
ভালো Algorithm

Correct · Efficient · Clear · Finite · General

Real World
কোথায় আছে?

Google search · Spotify recommendations · GPS routing · Instagram feed — সব Algorithm!

# Number Guessing Game — Full Algorithm import random secret = random.randint(1, 100) count = 0 while True: guess = int(input("Guess 1-100: ")) count += 1 if guess == secret: print(f"Correct! Got it in {count} guesses!") break elif guess > secret: print(f"{guess} too high! Try lower.") else: print(f"{guess} too low! Try higher.")
🏆 Golden Rule
প্রতিটি complex program = simple algorithm-এর সমষ্টি। বড় problem → ছোট ছোট ধাপে ভাগ করো!
